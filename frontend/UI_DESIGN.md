# UniFlow Finance UI Design System

## Color Palette
- **Primary:** #00B97A (M-Pesa Green) - Trust, Money, Growth
- **Secondary:** #1A1A1A (Deep Charcoal) - Modern, Professional
- **Accent:** #FFD700 (Golden Yellow) - Alerts, Highlights
- **Background:** #F5F7FA (Soft Grey/White) - Clean, Uncluttered

## Key Screens

### 1. Dashboard (The "Money Hub")
- **Top Card:** Total Balance (Combined M-Pesa + Bank).
- **Weekly Progress Bar:** A visual ring showing the 2,500 KES limit.
    - Green: < 50%
    - Yellow: 50-80%
    - Red: > 80%
- **AI Insight Bubble:** A floating chat bubble with a message from Gemma 4.
- **Quick Actions:** "Log Expense", "Check HELB Status", "Send Money".

### 2. HELB Planner (The "Survival Map")
- **Input Section:** Total Loan Amount $\rightarrow$ Semester Weeks.
- **Allocation Breakdown:** 
    - Rent (Fixed)
    - Tuition (Fixed)
    - Living Allowance (Weekly)
- **Countdown:** "Weeks remaining in semester".

### 3. Transaction Feed (The "Ledger")
- List of all transactions with icons (🍽️ for food, 🚌 for fare, 📚 for books).
- Integration of the "Debt Ledger" (highlighting who owes who).

### 4. AI Chat Interface
- A dedicated space to ask Gemma 4 questions like:
    - "Can I afford a pizza tonight?"
    - "How much did I spend on fare last week?"
